UI/UX Full Time On site

Frontend Developer (React)

CloudShift Labs

Build modern UIs using React and Tailwind.

2 - 4 Years

50k - 70k USD

New York, NY

Apply Now

Deadline: 25 June 2025

Job Overview

CloudShift Labs is looking for a skilled Frontend Developer (React) to build modern, responsive, and high-performance user interfaces.

You will work closely with designers and backend developers to deliver clean, scalable, and user-focused web applications.

Key Responsibilities

Develop responsive user interfaces using React.js

Translate UI/UX designs into clean, reusable components

Optimize applications for maximum speed and scalability

Collaborate with backend teams to integrate APIs

Maintain code quality through reviews and best practices

Required Skills & Qualifications

Strong experience with React.js and JavaScript (ES6+)

Good understanding of HTML5, CSS3, and responsive design

Experience with REST APIs and component-based architecture

Familiarity with Git and version control workflows

Ability to work independently in a remote environment

Nice to Have

Experience with Tailwind CSS or modern UI frameworks

Knowledge of performance optimization techniques

Basic understanding of backend technologies

Previous experience working in remote teams

What We Offer

Competitive salary with performance-based reviews

Fully remote working environment

Flexible working hours

Opportunity to work on real-world, scalable products

Supportive and growth-focused team culture

Application Process

  1. Analytics Corp
  2. Shortlisted candidates will receive a technical assessment
  3. Final interview with the engineering team
